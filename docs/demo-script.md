# Relay: 2 minute 45 second demonstration

Use only fictional data. Record a live Gemini run for the final submission. A video
made using the Scripted rehearsal button must be labeled as a rehearsal.

| Time | Screen and narration |
| --- | --- |
| 0:00–0:20 | EMT view. “The patient is eight minutes away. Relay gives the receiving team a shared picture before arrival.” |
| 0:20–0:40 | Connect the Nano, move it, and show changing acceleration. “These are real motion readings. Patient vitals are separately labeled simulated values.” |
| 0:40–1:05 | Update the field note and run Gemini. “The agent reads the report, simulated observations and available resources, then proposes an ATMIST handoff and preparation tasks.” |
| 1:05–1:40 | ER lead view. Show evidence links, unknown blood type, orthopedic consultation and OR standby. Edit if needed, then approve. “The lead approves dispatch; the model cannot order care or approve itself.” |
| 1:40–2:10 | Charge-nurse view. Acknowledge and mark Ready. Return to the lead view to show shared readiness. |
| 2:10–2:35 | EMT view. Add the worsening update. Show the new five-minute ETA and revised draft; existing staff acknowledgments remain. |
| 2:35–2:45 | “Relay turns a changing field report into a reviewed preparation plan, with clear ownership and visible readiness. The team still confirms the handoff on arrival.” |

Before recording: close Arduino Serial Monitor, reset the demo, arrange EMT/lead/staff
views in tabs, confirm Gemini is available, and check the duration stays below 3:00.
